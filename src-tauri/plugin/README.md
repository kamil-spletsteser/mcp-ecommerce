# E-commerce MCP — plugin dla Claude

Plugin wygenerowany przez aplikację **E-commerce MCP** na tym komputerze. Zawiera:

- **serwer MCP** `ecommerce-mcp` — lokalne binarium aplikacji E-commerce MCP uruchamiane w trybie `mcp` (stdio);
  tokeny sklepów pozostają w systemowym magazynie haseł i nie są częścią tego pliku;
- **skille**: `przeglad-zamowien`, `obsluga-zamowienia`, `produkty-i-stany`, `raport-sprzedazy` (BaseLinker) oraz `allegro-sprzedaz`.

Ścieżka do binarium w `.mcp.json` jest bezwzględna i dotyczy tego komputera. Po przeniesieniu lub reinstalacji
aplikacji pobierz plugin ponownie (E-commerce MCP → Połącz klienta AI → Pobierz plugin).

Źródła (sklepy) dodajesz i wyłączasz w aplikacji E-commerce MCP — plugin nie wymaga żadnej konfiguracji.
